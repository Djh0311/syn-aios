## Update Rules

- Add a decision when product, architecture, security, data, workflow, or rollout behavior is confirmed.
- If a decision changes, do not overwrite history silently. Add a new decision or mark the old one superseded.
- Link task and requirement rows to decision IDs when the decision constrains implementation.
