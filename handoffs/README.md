# 历史交接记录库

状态：**交接与复核记录，不是产品正本、当前状态、候选方案、任务入口或执行授权。**

本目录保存不同开发阶段、不同工作树和不同对话之间的交接材料。交接文件可以说明当时：

- 做到了哪里；
- 哪些结果已经验证，证据等级是什么；
- 哪些改动或工作树需要保全；
- 当时建议谁接手、下一步做什么。

交接中的“当前”“下一步”“唯一入口”“继续执行”“已授权”不会跨阶段持续生效。恢复任何工作前，都要重新核对当前用户指令、`docs/current-state.md`、当前版本库（Git）、源码和当前开发规则；不得直接照旧交接续跑。

如果交接中记录了用户拍板、长期产品要求或重要架构原则，应把内容和来源提取到当前产品正本或正式决定中。完成提取后，交接继续作为历史来源保存，不再与产品正本竞争。

Syn 的知识基础设施可以让智能体检索这些交接，快速理解历史、失败教训和保全边界；检索结果必须带时间和来源，不得把旧“下一步”解释为今天的任务，也不得把历史权限解释为当前权限。

本轮不批量移动既有交接。后续迁移必须先建立旧路径到新路径的映射，逐批更新引用并验证内容哈希与链接完整性。
