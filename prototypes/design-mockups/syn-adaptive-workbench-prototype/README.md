# Syn 自适应工作台前端原型

这是一个无后端、可直接浏览的交互原型，用于验证 Syn 如何把“对话是否需要重新开始、是否需要调整工作方式”变成用户不必学习技术术语的工作台能力。

## 本版验证什么

1. 新用户只要在首页说一句目标，就能开始工作。
2. 项目主管等关键角色需要改变工作方式时，先解释影响，再由用户决定。
3. 受限执行角色的小故障由 Syn 在既有授权内安静恢复，只留下可追溯记录。
4. 涉及范围、权限、隐私、费用或验收变化时，工作台必须停下，不提供绕过按钮。

## 保留的现有入口

左侧栏完全保留当前产品顺序：

- 主入口：项目、智能体
- 流转：想法箱、实验画布、发令台
- 积累：知识库、记忆层
- 中枢：技能、运行器
- 底部：设置

首页仍由左上角 Syn 标识进入。模型、供应商、会话编号等开发者概念没有新增为普通用户入口。

## 可操作流程

- 首页输入目标并点击“交给 Syn”，目标会进入“正在进行”。
- 在“需要你决定”中选择继续、暂停或稍后提醒；首页与智能体对话中的状态会同步。
- 在首页展开“Syn 刚刚替你处理”，或进入“运行器”，查看执行角色的自动恢复记录。
- 所有左侧栏入口均可点击；关键页面包含完整示例，其余页面展示本入口在工作台中的职责。
- 手机端可从智能体页直接打开角色列表，并切换项目主管、咨询、前端开发和体验检查。
- 暂未纳入本轮范围的按钮会明确说明，不会表现成点击失效。

## 视觉与交互取向

- 借鉴 Linear 的表面层级、细边框和低噪声信息密度。
- 借鉴 Raycast 的“先说一句要做什么”命令式入口。
- 保留 Syn 自己的浅色、克制、非技术用户友好的表达，不复刻两者的深色开发者界面。
- 主要操作目标不小于 44px，支持清晰键盘焦点、窄屏抽屉导航和减少动态效果偏好。

## 运行

直接打开 `index.html` 可以浏览。为避免浏览器本地文件限制，也可以在本目录启动任意静态文件服务器。

## 边界

本版本只模拟前端状态，不会真正创建任务、切换模型、开启新对话或修改项目文件。界面里的项目和运行记录是用于验证体验的示例数据。

## 已验证

- 桌面：1440 × 1000
- 窄屏：390 × 844，无横向溢出
- 目标提交、关键角色继续/暂停、跨页面状态同步、角色切换、移动导航和键盘焦点
- 浏览器控制台：0 error / 0 warning
