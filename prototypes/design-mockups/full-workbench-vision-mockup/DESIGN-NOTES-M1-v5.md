v2/v3/v4 在 `archive/`。本版按你的指令:**底子 = 现软件的真壳和真首页**(逐一读了 `productized-desktop-shell` 的 App.tsx / WorkbenchShell.tsx / HomeView.tsx / workbenchNavigation.ts / styles.css),改点分层叠上去,开「标注」能看清哪是原有、哪是改的。

## 一、底子:哪些是现软件原样(没动)

- **壳**:左侧 144px 分组导航(主入口:项目·智能体/流转:想法箱·实验画布·发令台/积累:知识库·记忆层/中枢:技能·运行器 + 设置)——**九入口一个没收编**(收编 07-02 被否,这版不再提);52px 顶栏(案印=回首页/最近项目/搜索/N 待审/项目数/↺/健康点);右竖条(秘·知·待·想·行·管 + 迷你统计 + 健康点);底 dock(秘书 orb + 输入条)。配色 token 从现软件 `styles.css :root` 原样取(米纸底/朱印/青绿主色),字体同(DM Sans 正文 + 宋体标题)。
- **首页骨架**:hero「N 件需要你看一眼」+ 双面板区(运行中/变更)+「最近工作」区(项目行 + 技能/运行器两块瓦片)——与真 HomeView 同构。
- **项目页骨架**:交办 tab 默认页 + 工作流 tab(真机验收过的现状)。

## 二、改点(每处都挂「改」标注,开「标注」可见)

1. **hero 的三个泛跳转按钮[去确认][去处理][去审批] → 正下方「等我拍板」就地清单**:5 张卡(批3/卡1/看1)+ 记忆便签,点开原地展开、一个主按钮当场办完,办完滑出、计数五处联动(hero/待审钮/秘书角标/窗口标题/组头)。这是本版最大的改动:从「告诉你有 5 件、自己去找」变成「5 件就在这,当场办」。成员全是现软件已有的东西(待批方案/卡住/交货黄牌/候选),改的只是聚合与摆法。
2. **dock 输入条:从秘书对话预览(readonly)→「说一句,开新活」真输入**:项目 chip + 回车/出方案;秘书 orb 和「打开秘书」保留。开工的口住进现成的输入条,不新造控件。说完自动识别项目 = Phase C 标注。
3. **「变更」空面板 → 「最近交货」流水**:现软件此处是诚实占位(change-feed 未接入);交货流水正好填这个坑。
4. **「运行中」面板行内文案 → 人话进度**:「正在:加金币加分逻辑(第 2/3 步)· 已 4 分钟」+ 行内「停」;原来是「N 工作项」。
5. **「最近工作」项目行 meta → 「在干 1 · 等我 3 件」**:原来是「N 会话」。
6. **项目页加「工作历史」列**(已拍需求·实现包待拍)+ **脸顶「这单的完整经过」可展开**(你说→方案·已放行时间戳)+ **「记忆」项目内 tab**(全局记忆层按项目过滤的同一份)。
7. **授权卡加「最坏情况+可回滚」行、主按钮带对象(允许并开始·改 1 个文件)、交货卡加「收货」**——三处均标「改」。
8. **右竖条「秘」点开 = 秘书待拍板面板**(分组直达首页对应卡)——现软件本有此面板位(RightDetailPanel),内容对齐。

## 七(记忆页重做)、记忆层 = AI 的随身笔记本,你是主编(2026-07-08 晚)

> **状态:未定稿——用户看过说「不太好」,且形态「还没想好,先不做」。** 现版(左列表右详情)只当占位,不作为记忆层定稿;推倒重来时三个候选形态供拍:① 一页档案(AI 把记忆写成一页人话备忘录,候选=铅笔批注描一下转正,坏记忆=红圈就地处理)② 对话式(问「你记得什么」,说「把那条忘了」——大头是 Phase C 能力)③ 极简清单(一列人话句子+改/忘两动作,候选置顶,其余全砍)。等用户想好再动。

用户令「把记忆界面再好好设计一下」。整页重做(它本来就兼「记忆中心布局重做」挂账的设计稿):

- **一眼三问**(顶部体检行,三个可点数字):几条候选等我确认 / 有没有坏记忆要看 / AI 出方案会带上几条。
- **左列表 右详情**(与项目页同构,零新学习):列表分四组——候选·等你确认(带来源:删怪单[属实]/治理钩子)/ **要你看**(维护检查发现,人话卡)/ 正式·本项目 / 正式·全局。
- **详情的重头 = 来龙去脉**:每条正式记忆一条小时间线——哪单攒的候选 → 你哪天确认转正 → **之后被带去干活几次、哪几单**(引用可见性=构想·待拍)。记忆从「一句话」变成「有出身、有战绩的资产」。
- **确认流**:候选详情卡带「哪来的」回链 + 冲突检查内联提示(检查=现软件已有,确认时刻内联=改);[记住]后**自动跳下一条候选**(收件箱式),列表行滑进正式组;与首页便签双向同源联动。
- **维护发现**:示例「疑似过期:index.html 是唯一游戏文件(观察到新增 style.css)」——[仍属实,保留][改写][废弃]三条路,处理结果记审计;正式记忆详情里也有联动提醒「去处理→」。检查只提醒不自动改(现状语义)。
- **生命周期**:编辑/升到全局/冻结/废弃/合并按钮全在详情卡上,统一挂 Phase D(命令有、界面未接全);版本行 Phase D。
- **收纳**:现软件 11 块治理面板收进列表底部「更多治理 ▸」一行。
- 徽标:确认制/召回 top5/检查/钩子攒 = 现软件已有;整页布局/人话维护卡/内联冲突提示/全局作用域呈现 = 改;生命周期/版本 = Phase D;引用次数与引用列表 = 构想·待拍。
- 验证:列表↔详情切换、[记住]自动跳下条、首页便签↔记忆层双向同步、维护发现就地处理、计数三处联动,全部机检过;截图核过。
