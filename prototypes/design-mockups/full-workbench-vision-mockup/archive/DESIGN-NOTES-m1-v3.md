## 一、一句话:整个工作台 = 一个收件箱 + 一个说话框

打开应用 3 秒内回答你唯一关心的问题:「**有没有事等我?**」
- 有 → 排在最上面,一张卡展开、一个主按钮当场办完,办完一件少一件;
- 没有 → 「在干」的单安静地躺在下面(灰点呼吸),交货或卡住会自己浮上来叫你——你可以关掉走人。
- 想开新活 → 永远在底部的「说一句」框(⌘K 直达),回车就完事。

导航只剩两个:**收件箱 / 项目**(智能体·记忆中心·审计收进「更多」)。秘书不再是一块单独的面板——**收件箱「等你」组就是秘书的活**(汇总待拍板),重复的东西合并掉了。

## 二、这不是拍脑袋:五路网研 → 设计决定对照

| 设计决定 | 依据(网研一手来源) |
|---|---|
| 首页=「等你」置顶的收件箱,不是仪表盘 | Linear Triage、Claude Code agent view(Ready for review/Needs input 永远最上)、Google Critique attention set(97% 满意度)、LangChain Agent Inbox;dashboard 研究:72% 汇报型仪表盘被弃用 |
| 每单一行:目标+AI 最新一句人话+时间+红「批/卡/看」徽章 | 微信会话列表(地球上验证最充分的多线程界面);Claude Code agent view 每行人话摘要;「数字红点只给需要人动手的事」 |
| 不做百分比进度条;「正在:干什么 · 已 N 分钟」+四段阶段条 | agent 任务没有真实百分比,假进度条撒谎;Domino's Pizza Tracker/美团订单页(4-5 段人话阶段);labor illusion 研究(HBS:展示「正在干哪件事」感知价值+8%,Uber 实测取消率-11%) |
| 批准卡一屏放下:干什么/碰什么/怎么验/最坏情况+可回滚/主按钮写动作带对象 | 微软 NEAT/CHARGE US(可用安全);Google 200 行定律(超一屏=假批准);NN/g:按钮写动作不写 Yes/No,undo 比 confirm 更给胆量;Jules 的 HN 差评反面教材(审批控件消失) |
| 主管意见=灰便签,无按钮、不挡路;绝不长得像闸 | Chrome 权限弹窗 85% 被无视的教训(高频参考拖垮真拍板);Google Critique resolved/unresolved 分流;「拍板/参考/黄牌三形态永不混用」 |
| 卡住卡=人话原因+已干完可保留+2-3 条路;失败永不折叠 | Claude Code agent view(Failed 永不折叠);answer.ai 的 Devin 实测(抢救半成品比失败更耗时);NN/g 空状态三准则 |

| 常驻「说一句」框=开工唯一仪式 | Things 3 Magic Plus(拖到哪建到哪);Claude Code agent view 底部输入框(打字=开单) |

## 三、两屏怎么答包里的必答题(功能不丢)

**屏1 收件箱**:①哪些事等我拍板 = 「等你」组(批3/卡1/看1,跨项目混排,含卡住单——研究说有按钮的都算等你)+ 记忆便签(3 条候选,便签形态不占拍板位);②各项目跑到哪 = 「在干」组每行人话进度,「最近干完」沉底;③想开新活 = 底部说话框(项目手选=现状,说完自动识别=Phase C 标注)。
**屏2 项目页**:左=该项目单据列表(一单一行,含历史);右=选中单的**完整经过**(你说→方案卡[已放行有时间戳,折叠可查——所批即所跑]→干活卡[阶段条]→交货/卡住卡)——「回看任意一单当时的脸」升级成「回看整单经过」。工序画布、项目记忆 = 第二层 tab:画布答「工作流与交办的关系」(同一份图,批前浮卡上、批后落画布);记忆 tab 答「项目记忆=全局记忆中心按项目过滤的同一份」。

**现有功能保全对照**(现状盘点逐面核):五态全在(说=说话框/批=授权卡/干=阶段条+步骤/交货=证据+黄牌+属实沉淀/卡住=三条路);主管两意见(灰便签×2);超时自动打回+重拆不重做(卡住卡原文);会话选择+看原始对话(深挖链);工序图+画布入口;记忆候选确认制+召回;秘书功能(待拍板汇总=等你组,让 AI 解释可挂组头——M2 补);纯建议诚实脸(改进单)。**没有一个现状功能被删,只是换了住处。**

## 四、标注层(默认关)

「标注:关/开」在左下角。开了才显示三种记号:现在就有(绿)/ Phase C·D·E(虚线)/ 构想·待拍(点线,含「当年否过·供重议」)。默认关=纯产品体验。关键标注:收件箱首屏与导航收编=**构想·待拍(当年否过·供重议)**;跨项目聚合摆法、「最坏情况」行、「收货」动作、便签形态=待拍;说完自动识别项目=Phase C;多项目并行=Phase E;其余(人闸/黄牌/自动打回/所批即所跑/候选确认/进度与停)=现在就有。
