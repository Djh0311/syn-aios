### 屏1 · 首页(项目群 + 今日桌面)

**一眼答三问**,页面从上到下就是三问的顺序:

1. **哪些事等我拍板** → 「等我拍板 · 8 件」置顶:6 行(3 待批方案 + 2 主管提醒 + 1 记忆候选打包行),每行 = 项目章 + 一句话 + 去处;mario 的三行**直接点进项目页对应的脸**(批/交货/纯建议)。双徽标注明:数据 = 秘书「待你拍板」**现在就有**;跨项目摊上首屏 = **构想·待拍**。
2. **各项目跑到哪** → 三张项目卡,每卡固定四件事:状态行(跑着的进度「第 N/M 步」)/ 卡住或等批行 / 最近一单交货行 / 「等我 N 件」计数章(点了进项目并展开秘书)。
3. **想开新活** → 三个口:顶栏 ⌘K(Phase C)/ 项目卡上直接说一句(mario 卡真可点:输入 → [出方案] → 落到交办「说」脸并预填,toast 说明先出方案你批了才干)/ 项目页里 + 新交办。卡上入口挂「入口摆法·待拍」徽标。

Phase E 能力示意:kt-erp / 产品手册整卡挂 Phase E(自动干真实项目 = 乙才放开,卡上白纸黑字写明「今天只圈测试项目」);页底「多项目接力」条(kt-erp 交货 → 自动开单给产品手册)Phase E 徽标 + 「接力不绕人闸」一句。

历史红线处理:首页整屏、项目群总览、导航收编三处均挂**「构想·待拍(当年否过·供重议)」**,徽标 title 里写明 07-02 否案背景——原型不是翻案。

### 屏2 · 项目页

**v1 三栏为基,细化不重造**:左工作历史(原样保留,含五单假数据与「已拍需求·待实现」徽标)/ 中五态主区(v1 骨架 + 按现状盘点补细节,见下)/ 右秘书三级(原样 + 跨项目分组)。

包内两道必答:

1. **「工作流」tab 与交办的关系** → 项目内 tab 行:交办(默认)· 工作流 · 记忆。工作流 tab 一句话定位:「**这张图 = 交办批过的工序**——批前浮在授权卡上,批后落到这里变真节点,跑到哪亮到哪」(所批即所跑·现在就有)。图内容与交办「正在干」的三步**同一份数据**(同一单「加计分板」);正在干的脸上有「在画布看这张图」直通链;任务节点只看不点(不给绕人闸的口子)写在图下。画布本体能力(多工作流/全屏 HUD/发令台/手动挡)以 chip 列出、全部「现在就有」;「工序沉淀成模版」挂 Phase D。
2. **项目内记忆入口与全局记忆中心的关系** → 新增「记忆」tab(挂「入口·待拍」徽标),开宗明义:「**这里 = 全局记忆中心按本项目过滤的同一份数据,不是另一套库**」。内容:正式 2 条(带「升到全局」Phase D 章)+ 候选 3 条(转正按钮 = 确认制·现在就有)+ 「去全局记忆中心」口(M2 屏4)。与交办双向接:说脸的「出方案会带上 2 条项目记忆」可点、直达此 tab;交货脸 [属实,沉淀] 的候选落在这里。

五态细化(相对 v1,全部按 2026-07-08 现状盘点):批脸补「用哪个对话干」收纳行(展开可换/开个新的)+「按工作流来」开关行 + 想改直接说输入框 + 越界会停一句;卡住脸的超时自动打回从 v1 的「包已派」**改成「现在就有」**并写明「重拆带着『前面已完成的事,不重做』」;干脸补「最长十几分钟」等待预期;交货脸黄牌行注明「(黄牌)」。

## 二、与 v1 的差异点及理由(凡偏离已认元素处)

v1 已认元素(水墨 token / 徽标体系 / 三栏 / 五态 / 假数据用真单)**除秘书全页骨架外全部保留**(见差异 10);token 是从 v1 `:root` 原样复制的(13 个变量,diff 逐字节同)。差异逐条:

1. **加了全局壳(六面导航顶栏)**,v1 顶栏的「交办/工作流/记忆」下沉为项目内 tab 行 → 本包画的是整台不是单项目页,导航必须升到全局;项目内 tab 是 v1 那排按钮的原位继承。
2. **新增首页整屏** → 包内屏1 要求;v1 没有首页。挂否案徽标(见上)。
3. **秘书铃计数 6 → 8、面板加项目章与跨项目分组** → 多项目成了终局常态,秘书是跨项目一本账(与首页同源);mario 单项目部分与 v1 完全同构(1 方案 + 2 提醒 + 3 候选 = 6)。
4. **卡住脸:超时自动打回从「包已派」改「现在就有」** → 现状盘点 面2「自动行为」明载已落地(质量债包已收口);现状正本最高,v1 那颗徽标已过期。
5. **批脸加「按工作流来」开关行与工序图说明** → 现状盘点 面2「批」明载;v1 漏画。emoji 单如实标「AI 建议:不用——这单简单,秒出」(条件式工序图:简单活无图秒出,不为演示而硬塞图)。
6. **工作流 tab 从「原型不展开」变成真页** → 包内屏2 必答「工作流 tab 与交办的关系」,不画答不了。
7. **记忆 tab 从「原型不展开」变成真页** → 包内屏2 必答「项目内记忆入口与全局的关系」。
8. **⌘K 从纯摆设变可点面板** → 高保真+关键流可点的要求;面板内容只做「不绕人闸」的说明,不假装 NL 已实现(Phase C 徽标不摘)。
9. **交互提示一律 toast 说明「示意」** → 原型里点不通的地方不冒充能用。
10. **秘书全页骨架 M1 未含**(v1 有 #secFull 三卡页)→ 包内拆批:秘书全页 = M2 屏5 正题,M1 只保留入口(「全页 ↗」+「待实现」徽标);三级空间(mini/面板/全页)不推翻,第三级 M2 按 v1 加深。
11. **纯建议脸的「仍要允许并开始」toast 改口** → v1 写「纯建议照样能跑」;现状正本(面2 自动行为)是**开工口对纯建议直接拒(不建垃圾授权)**——按「现状正本最高」改成如实说「会被干净拒掉」。按钮本体保留(现状即「降次不删死」)。
12. **一批小细化的归位**(§一已述,此处立账):批脸会话行改收纳式+可展开、加「想改直接说」输入框;干脸补「最长十几分钟」与画布直通链;交货脸自述行注「(黄牌)」;advice 主管意见「写根为空」改写「不动文件」(去黑话);秘书面板首页默认 mini、项目页首次进入自动展开(v1 默认展开的折中,避免首页与「等我拍板」重复)。
