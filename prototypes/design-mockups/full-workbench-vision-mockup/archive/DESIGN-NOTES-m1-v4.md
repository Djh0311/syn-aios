## 二、从 v3 网研保留下来的显示语言(证据见 archive/DESIGN-NOTES-m1-v3.md §二)

- **等我拍板 = 一条跨项目队列**,红字「批/卡/看」徽章 + 人话摘要;点开原地展开、一个主按钮当场办完,办完滑出、计数联动(首页/导航/秘书细条/窗口标题四处同步);
- **授权卡一屏放下**:要干什么/会碰什么/怎么验/最坏情况+可回滚/用哪个对话;主按钮写动作带对象(「允许并开始 · 改 1 个文件」);
- **主管意见 = 灰便签**,无按钮不挡路,永不长得像闸;
- **在干 = 余光区**:灰点呼吸 +「正在:干什么 · 已 N 分钟」,不做百分比进度条;项目页里配外卖式四段阶段条(已放行→在干→自检→交货);
- **卡住卡**:人话原因 + 已干完可保留 + 三条路按钮;**交货卡**:黄牌置顶 + 证据行(grep 输出)+ 属实沉淀;
- **记忆候选 = 便签形态**,批量确认不弹窗;
- **标注开关**(左下角,默认关):开了显示 现在就有/Phase C·D·E/构想·待拍(含「当年否过·供重议」)。

## 三、功能保全与台账

现状功能一个没删(五态/两道主管意见/超时自动打回/所批即所跑/工序画布/记忆确认+召回/看原始对话/秘书三组+让AI解释+零写入边界话)。假数据同一批单:mario 六单(计分板在干/巡逻怪卡/emoji批/改进纯建议/删怪交货黄牌/加暂停全绿)+ kt-erp 三单 + 手册两单;账 = 等我拍板 5 + 候选便签 3、在干 2。工序画布/项目记忆 tab 沿包内屏2 必答(图=批过的工序·同一份;项目记忆=全局按项目过滤的同一份)。

## 四、这版请你重点感受

1. 左导航的位置和六个入口,顺不顺手?
2. 首页「说一句 → 等我拍板 → 在干 → 项目卡」这个从上到下的顺序,对不对?
3. 「批」卡展开、点「允许并开始」那一下(卡片出队、计数变);
4. 项目页:默认一张脸 + 「完整经过」可展开——这个折中留不留?
5. 右侧秘书细条(📮+数字)默认收着,点导航「秘书」或 📮 展开——这个存在感够/多?
