## 2. 每屏必答清单(设计规格核心)

**全局(所有屏)**:导航按终局提案(可少于现九入口·收编方案打「供重议」徽标·六面必须可达);顶栏 ⌘K「说一句话直接开工」=Phase C 徽标;秘书常驻入口(铃+计数·三级空间沿 v1);徽标三种(现在就有/Phase C·D·E/构想·待拍);**多项目=终局常态**:假数据至少 3 个项目(mario-test + 虚构 kt-erp + 一个文档类),各处不同状态;词表全人话——禁 planned_task_id/dispatch 类黑话、界面称「自述/汇报」不称口供、**禁「审批」**(意见不是闸)。

**屏1·首页(项目群+今日桌面)**:一眼答三问——①哪些事等我拍板(跨项目待拍板·与秘书同源)②各项目跑到哪(项目卡:状态点/最近一单/跑着的进度/等我的事计数)③想开新活(⌘K 或项目卡上直接说目标);Phase E 能力(多项目接力)徽标示意。

**屏2·项目页**:v1 三栏为基**细化不重造**;补答:「工作流」tab 与交办的关系怎么呈现(工序图/画布入口);项目内记忆入口与全局记忆中心的关系。

**屏3·智能体页**:定位照定稿原文(交办=有结构有闸的自动跑;智能体=手动直连);**桥双向**——交办侧「看原始对话」已有,智能体侧怎么标注「这条会话属于哪单交办」(构想·待拍);列表/对话区沿现 app 骨架(分组/折叠)。

**屏4·记忆中心**:候选→正式确认流(现在就有)+ Phase D 完整生命周期(编辑/废弃/冻结/合并/升降全局)徽标示意;「这条记忆被引用过几次」可见性(构想·待拍);**这屏兼任旧挂账「记忆中心布局重做」的设计稿**。

**屏5·秘书全页**:沿 v1 三栏加深——机会简报长什么样(B3+)、对话式秘书(Phase C 同期·徽标);页脚一句架构 §7 边界:「秘书零写入·不判断·不派活」。

**屏6·审计回看**:**给人看的审计**(不是 json 摊平)——按单/按天时间线:谁(角色)干了什么、两道主管意见、你的拍板记录;信任阶梯示意(升档记录/换脑人事事件·愿景 §4·构想·待拍)。
