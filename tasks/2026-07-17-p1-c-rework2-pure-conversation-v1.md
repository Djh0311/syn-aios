# 修单2:P1-C 对话流=纯对话·方案卡移右区·提示牌退场 v1

日期:2026-07-17 · 档位:轻档·前端(呈现层为主,允许右区视图小接线) · 执行者:执行线 · 性质:**用户实物验收修正方向**——总执行计划 P1-C 行「方案卡/追问/交货卡=消息」被实物否定,用户拍:对话=像日常交流一样即时说话;方案定稿后卡在右侧显示,不进消息流。计划正本随收口修订,本单先落实物。

## 用户原话(定性依据)

「我以为是像我们现在这样的交流方式,像日常对话一样,即时的交流想法。然后确定之后会弹出方案卡或者在右侧显示方案卡。现在是像对话,但给我的消息还是方案卡。」+ 两条 ⚠ 提示(旧方案预警/只读单说明)点名不要。

## 修什么

1. **A1 中栏对话流只留「话」**:保留=你的消息/主管追问(待答+输入框)/主管已答折叠/主管短讯。**方案卡、交货卡整卡从消息流退场**;方案生成时主管在对话里说一句人话短讯(如「方案好了,放你右手边了——看一眼,能跑就批」;交货同理「干完了,结果在右边」),短讯可点=聚焦右区对应视图。短讯是主管的话,不是新提示牌;文案走人话,禁机器词。
2. **A2 方案卡挂右区**:右区视图集加「方案」(与工序图/治理保证/怎么跑并列);方案存在时右区默认显示方案卡(修单1 的实体卡形原样搬过去,段落序=DESIGN §三·五 不动);**批准动作行随卡在右区**;交货卡同法(交货态右区默认交货卡,[属实,沉淀] 语义零改)。say 态右区提示照旧。
3. **A3 两条提示牌退场**:「⚠ 这是 N 天前的旧方案…建议重新说一遍」与「⚠ 这单是只读的——AI 只看不改…」两条横幅从呈现删除(判定机制/只读机制本体零改,只删牌;若旧方案确需提醒,并入主管短讯人话一句,不立横幅)。全对话面扫一遍同类 ⚠ 横幅,有则一并列清单报回处置。
4. 左栏锚点行为随 A1 调整(锚点跳到对应对话位置+右区聚焦该单方案/交货)。
