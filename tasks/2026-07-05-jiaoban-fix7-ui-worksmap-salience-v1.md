## 2. 建什么

### 2.1 像图(核心)
- `<ol>` 列表 → **步骤框纵向流**:每任务一个小框(步骤号 + 任务标题),框与框之间**连线+箭头**(纯 CSS border/伪元素 或内联 SVG,**不引库**);依赖不是简单上下顺序的(等多个/跨步),在框上挂「等:X」小标签补充。
- 跑用现有 CSS 变量配色(暗色可读);任务标题照旧人话,**不露 planned_task_id/node_id**。
- warnings(残图/钳位)照旧列在图下小字;「完整工序图可在上方『工作流』标签里看大图」提示保留。

### 2.2 图好了有动静
- `previewTasks` 从 null → 非空的那一刻(仅在批面时):
  - 图区块**短暂高亮**(边框/底色 1-2 秒 CSS 动画,一次性,别循环闪);
  - **按钮旁状态话**(用户视线所在):loading 期显「工序图绘制中…(可先批,先批就按现场拆)」→ 图好后换「**✓ 工序图好了——你批的就是这份图**」(把"所批即所跑"的保证说出口);预拆失败显现有降级文案不变。
- **不做滚动劫持**(不 scrollIntoView 抢用户视线;高亮+按钮旁话足够)。

### 2.3 不变的
- 触发条件(开关/AI 建议)、预拆调用、缓存、approved 传参、loading/error/单任务/准备中四分支语义、简单活零图区——**全不动**。
