## 1. 建什么

### 1.1 三区布局(交办 tab 的新形态·Shell 层)
- **左**:历史折叠条(默认 ~26-32px 图标条·点开抽屉式展开现有 `JiaobanHistoryColumn`·再点收回);
- **上**:交办区 = 现有 `ProjectJiaobanPanel` 主体(五态照旧·内部逻辑零改·容器高度受阶段控制);
- **下**:画布区 = 现有项目工作流画布**只读嵌入**(节点跑到哪亮到哪照旧·「运行选中节点」等编辑操作在嵌入视图**隐藏**·全屏 HUD 按钮保留)。

### 1.2 阶段自适应主区(按 `JiaobanPhase` 切)
- `say`/`authorize`/`binding`:交办区为主(约 65-75% 高)·画布矮条(能看见节点行即可);
- `running`:交办缩成**状态条**(进度+[停下]+人话一行·现有件抽薄呈现)·画布为主;
- `done`/`blocked`:交办回主位(交货/卡住脸完整显示)·画布矮条;
- 切换要稳:相位变化 = 容器高度/显隐切换(CSS 过渡即可),**不卸载**面板与画布组件(防状态丢失·画布重挂载会丢视口);用户手动拖过的分隔线(若实现可拖分隔)在本相位内记住,切相位回默认。

### 1.3 旧「工作流」tab 降级(过渡·已拍)
- 保留 tab 与完整画布视图(编辑/发令台/多工作流能力都在那)·tab 标签可注「(完整视图)」;合一页画布区加「在工作流页打开」跳转;**不删任何现有能力**。

### 1.4 死线级 UI 原则
- **人闸庄重感**:[允许并开始]始终在交办区、始终是页面视觉最重的动作;`authorize` 相位画布仅只读预览;
- 五态词表/黄牌/死配对/永不冻:零改动(布局不碰逻辑);
- 挤 = 违约:任一相位下交办主内容不可产生横向滚动、按钮不可被画布挤出可视区(离线断言盯住)。
