## 2. 建什么

### 2.1 部分①·交办页工作历史左栏(`ProjectJiaobanPanel.tsx` + 面板 css)

- **布局**:交办 tab 变两栏——左 ~250px 历史栏 + 右主区(现五态一块面,**行为 0-diff**);窄窗口(<~900px)历史栏可收成顶部横条或折叠,不许把主区挤破(渲染真机验);
- **历史栏**:头部「工作历史」+ **[+ 新交办]**(→说脸);筛选 chips:全部/等我的(pending+卡住+交货有要看)/跑着;列表项 = 状态点 + goal 首行(ellipsis·复用溢出修法先例)+ meta 行(时间 + state_note 尾巴);
- **状态点映射**(九态英文键→人话/配色·词表死线):pending○等你批(stale 标旧)/ advice◐纯建议 / confirmed_not_run◌批了没跑 / running●跑着(done/total)/ blocked⚠卡住 / done✓交货(note 带「有 N 项要看」则黄点缀)/ declined·superseded·changes_requested=灰系终态一组;
- **行内快捷**:**仅最新一条卡住单**给[接着跑](调现成 continueRun——接着跑语义只对当前授权有效,旧单不给防误导);其余单不放行内按钮;
- **选中行为(关键·别过度造)**:默认选中=**当前单**(现有五态流原样);点**非当前**历史单 → 主区显示**该单详情卡**(只读:目标全文/状态人话/时间/进度 done¬al/意见 flags[结果·边界 verdict 人话化]/`correlation=time_window` 时小字「归属按时间近似」/一句去处「具体过程去『工作流』tab 看」——**不做跨 tab 接线**,文字指路即可);详情卡有[回到当前]。**不要试图为旧单回放完整五态脸**(旧单 outcome 不全持久·诚实显示读模型有的);
- **刷新**:挂载/交货翻脸/重拆后重拉一次;不轮询(便宜够用);
- 空历史 → 「这个项目还没交办过活」+ [+ 新交办]。

### 2.2 部分②·秘书看板(新 `SecretaryBoardView.tsx`)+ 右栏不挤

- **看板视图**(新组件文件):四列泳道,卡片式——
  - 「**等你拍板**」= pending_board 待批方案(卡:目标首行/项目/时间/旧标注);
  - 「**主管提醒**」= pending_board 主管提醒(卡:人话一句/来源单);
  - 「**记忆候选**」= pending_board 记忆候选(卡:claim 首行);
  - 「**风险与建议**」= risk_signals + suggestions(现成);
  - 每卡带**去处**:[去处理] 按钮 = 现成 `onNavigate` 切对应视图(项目/记忆)+ 卡上文字指路;**深链(直达具体项目具体单)不做**——那要新导航方案,等整台原型 M1 拍板(卡上如实文字指路即可);空列显「这列干净」;页脚边界话「秘书零写入·提醒不是命令」;
  - [让 AI 解释现状] 从右栏**挪进看板**顶部(同一现成命令·右栏瘦身的一部分);
- **入口**:右栏秘书摘要头部 [打开看板 ↗] + shell「秘书」铃点击直达看板;**左导航不增删入口**(红线——看板经铃/右栏可达);实现走现有 view 切换机制(App.tsx **窄口**:ViewKey 加一键+渲染分支+把 secretaryContext 传进看板,±25 行内);
