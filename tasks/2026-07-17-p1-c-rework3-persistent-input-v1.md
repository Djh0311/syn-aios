# 修单3:P1-C 中栏常驻输入框·按状态路由既有三通道 v1

日期:2026-07-17 · 档位:轻档·前端(纯路由,零新后端) · 执行者:执行线 · 性质:用户真机验收「结构没有问题」后点名补洞——「中间的对话栏既然是负责对话为什么没有输入框」。

## 拍板

中栏底部**常驻输入框**(对话软件的自然位置),提交时按当前状态路由到**既有三通道**,零新命令:

| 当前状态 | 用户的话路由到 | 既有通道 |
|---|---|---|
| 主管有待答问题 | 答复该问题 | `submit_supervisor_resident_answer`(P1-B) |
| 方案在批(authorize) | 按我说的改=修改意见重咨询 | 既有 amendment 路径 |
| 无活动单 / say | 开新交办首问 | 既有 consult 入口 |
| 跑着(running/binding 等) | 禁发 | placeholder 人话「正在干活——有话等交货或卡住时说」(运行期双向化=阶段三,诚实呈现现状,不是新牌) |

- 待答时输入框沿用答复语义(修单1 的追问下挂框**合并进常驻框**,不留双框);
- 右区方案卡上的修改输入框本轮**保留并存**(P1-D 人闸收敛时再清,别一轮改太多);
- blocked 卡住脸=P3-C 通道照旧零碰。

## 红线
