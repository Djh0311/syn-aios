# 修单4:P1-C 对话流聚焦当前单·历史单折叠 v1

日期:2026-07-18 · 档位:轻档·前端(纯呈现分组,零逻辑改) · 执行者:执行线 · 性质:用户真机点名——「现在对话里显示的是所有方案的记录,要改」。

## 病征

中栏对话流三个数据源全是**全量历史**:`userTurnsFromProposalHistory(proposals)` 把每个历史方案的用户话都生成消息;`artifactNoticesForConversation` 给**每个**方案/交货各配一条「方案好了,放你右手边了」「干完了,结果在右边」短讯(N 单=N 条重复短讯);黑板 `supervisor_message` 按 workflow 跨单累积。结果=打开对话看到的是所有方案的记录平铺,当前对话被淹没。

## 改什么(形态拍板:聚焦当前,历史折叠)

1. **A1 默认只渲当前单对话**:当前活动单(最新 proposal 及其后的消息;含它的用户话/主管追问问答/方案·交货短讯/等待态)完整显示;**更早的单收成一条紧凑折叠行**(如「更早的 3 单对话」,`<details>` 语义,默认闭合)。
2. **A2 折叠段展开形态**:按单分组的紧凑记录——每单:用户目标一句+该单问答(沿用已答折叠)+该单短讯(可点聚焦右区对应方案/交货,行为照旧);不复述实体卡内容。
3. **A3 视口停最新**:进入对话/切换项目/新消息落地,滚动停在最新消息(聊天惯例);左栏锚点点历史单=自动展开对应折叠段+滚到该单位置(`scrollToConversationMessage` 现成,锚点行为不降级)。
4. **A4 分组判据**:按 proposal 时间边界分组(某单的消息=该 proposal 创建至下一 proposal 创建之间的条目;黑板 entries 按 created_at 归组);判据写成纯函数进 `JiaobanConversation.tsx` 并配离线断言——**注意 Panel 行数水线(现 1981/2000,只余 19 行),分组逻辑全放 JiaobanConversation.tsx,Panel 只传数据**。
