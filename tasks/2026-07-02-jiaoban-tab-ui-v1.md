## 2. 建什么

### 2.1 tab 摆位
- `ProjectWorkspaceShell` 工具 tab 加 `jiaoban`(标签「交办」),**设为项目默认 tool**;原 `workflow`(项目工作流/画布)保留原样。总览/交接/资源不动。

### 2.2 五态一块面(同一容器,随状态换内容,不弹窗)
1. **说**:大标题「想让 AI 干点啥?」+ 多行输入 + [出方案](调 `runProjectConsultation`;等待态明显——真咨询 1–2 分钟,显示「AI 正在读项目、想方案…」,不冻不哑)。
2. **批(授权卡·定稿字段,一条不少)**:
   - 我来做(一句话,来自方案 goal_summary/user_goal 的人话化)
   - 会改的文件(来自 proposed_steps 里的「目标文件:…」行;没有则不显此行)
   - 改完怎么验(acceptance_criteria)
   - 用哪个对话干:◉ 开个新的(默认) ○ 接现有(列出本项目可选会话;数据源用现成会话列表)
   - 🔓 需要你允许:改这个测试项目(仅当方案含写范围;纯咨询方案不显此行)
   - 「碰到越界或拿不准的,会停下来问你,不硬来」一句总的
   - 「想改就直接说」输入框 + **[按我说的改]**(把原目标+这句意见拼成新目标重调 `runProjectConsultation`,新方案仍在这张卡上出)
   - **[允许并开始]**(调 §0 说的那个隔离 action;传 session_choice)/ **[先不做]**(拒绝,回「说」态)
3. **干**:人话步骤进度(轮询 `getProjectWorkflowChainStatus`,把节点/链状态翻成「正在…第 x/y 步」;**主路径不出现节点 id/链 id**)+ [停下](`stopProjectWorkflowChain`)。
4. **交货**:「✓ 做好了」+ 一句结果(chain outcome 人话化:完成 x 步)+ 产出概要(proof/改动文件列表,能拿到什么显什么,拿不到就写明「详情见工作流 tab」)+ [继续弄别的](回「说」态)。
5. **卡住(永不冻)**:停因人话(直接用后端 `outcome.message`——已带具体原因,别包含糊话盖住)+ 下一步按钮(复用已提交的「重新出方案」入口逻辑 / needs_binding 提示等现成分支)。**任何终点必有至少一个下一步按钮。**

### 2.3 词表清洗(主路径)
- 主路径**禁止出现**:scope / 绑定 / 派发 / 节点 / 工作项 / prepare / dispatch / workflow_id。词表:活、方案、允许、进行中、做好了、卡住了、停下、重新出方案。
- 原画布侧栏那批治理卡(方案与授权/拆任务/准备派发)**保留在「工作流」tab 侧栏当手动挡**,不删(override 用),但交办 tab 主路径不引它们的黑话文案。

### 2.4 老实标注
- 非测试项目打开交办 tab:显示「自动干目前只在固定测试项目开通;这个项目现在可用智能体直连」+ 跳智能体入口。**不装能跑。**
