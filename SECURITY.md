# Security

Syn is a pre-1.0 local-first desktop workbench. This file does not claim a security SLA, a published bounty, or a completed third-party audit.

## Report a vulnerability

Please do **not** open a public GitHub issue for a vulnerability, credential leak, or exploit.

Contact the primary maintainer through GitHub: [Djh0311](https://github.com/Djh0311).

Include:

- the public commit or tree if you can name one;
- impact and a minimal reproduction;
- whether any secret or personal data was exposed.

Do not attach real user data, tokens, or private project files.

## Scope notes

- Isolated fixtures, synthetic profiles, and local working copies are not production deployments.
- External connectors, packaged releases, and long-term real-world operation are not claimed yet.
- Please do not publish a proof of concept that would let someone attack another person's machine or data.
