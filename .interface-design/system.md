# Syn 知识工作台界面系统

## 方向

- 产品意图：让知识工作者在一个安静、连续的桌面工作台里阅读、编辑、追踪关系和整理 Canvas。
- 结构参考：以冻结的 Obsidian 核心桌面结构和高频交互为参照；只复刻通用工作区体验，不复制品牌、图标包、私有代码或插件生态。
- Syn 表达：暖纸、墨色、茶色、青玉状态、细发丝边；沿用现有 token，不另造一套视觉语言。
- 主次关系：中央内容或连续画布永远是主焦点；活动栏、左右栏、浮层和按需面板只服务当前任务。
- 密度与深度：桌面工具密度，4 px 节奏；主要用边界、表面明度和克制的选中态表达层级。禁止渐变、营销式大卡片、重复大标题和无必要的新阴影。

## 已接受的复用模式

### 临时面板的实际触发器回焦

- 打开时用组件本地 ref 记录真实 `event.currentTarget`，每次打开覆盖旧值。
- Escape、显式关闭和取消返回同一个仍 connected 的实际 opener。
- 内容选择成功后返回连续工作舞台，不返回已经消失的空态入口。
- fallback 必须是当前组件内稳定、可解释的目标，并保证焦点不落到 `body`。
- 关闭完成后清理陈旧 opener。
- 禁止用全局变量、localStorage、文案/CSS selector、DOM 顺序或延时轮询猜测 opener。
- 验收必须比较真实 DOM identity 和 `activeElement`，不能只比较按钮文本。

### Overlay 与临时工具

- 打开后焦点进入首个有效控件；Escape 卸载 overlay，并回到本次真实触发器。
- backdrop 保留底层工作区上下文，前景面板具有明确但克制的层叠关系。
- 不以强制点击、runner 注入 `.focus()` 或永久第二份状态制造通过。

### 可折叠侧栏

- 折叠状态同步 `aria-hidden` 与 `inert`，并让后代退出 DOM、Tab 和辅助技术路径。
- 恢复入口留在活动栏或当前壳的稳定控制面，不在折叠栏内部留下幽灵焦点。

## 待实施的 Graph 方向

- Graph 应读作关系网络而不是卡片列表：轻量节点、清晰标签、细连线、连续可缩放舞台。
- 当前/选中节点使用克制的 Syn accent；邻接关系比路径、标签和统计元数据更优先。
- 筛选、范围和计数属于紧凑 chrome，不得再次形成大标题加整行表单的管理页。
- Graph 保持只读投影；节点只通过既有 typed handoff 打开 Syn 原生笔记，布局不得写回 Markdown 或 vault。
- 具体尺寸和通过阈值由 R3D red-first 浏览器证据冻结，本文件不预先虚构数值。
