# 决策:项目「交办」tab · 好用定稿(Phase A 体验形状)v1

日期:2026-07-02 · 拍板:用户(原话「就这样可以」)· 记录:主导线。
上承:`docs/plans/2026-06-27-complete-workbench-phased-roadmap-v1.md` Phase A——本决策把 Phase A 验收从「角色循环能跑通一遍」抬成「一种活(改测试项目)能**好用地交办一遍**」。

## 总纲(一句话)

**在项目里加一个「交办」tab(默认页):说一句目标 → 批一次 → 自动干 → 交货带证据;复杂活多给一张工序图;其余工作台一切不动。**

好用五柱 = Phase A 验收标准:**少动手 / 看得懂 / 等得安心 / 卡了有路 / 交货有交代**。
判据(以后每加一个东西先问):它让用户**少等、少点、少懵**了吗?三个都不占 → 藏后台或砍掉。

## 摆位

- **动**:项目内部——新增「交办」tab 当项目默认页;画布退成「工作流」tab(不删,新职责=看这单活的工序图/进度)。
- **不动**:工作台外壳、左导航九入口、智能体页、右侧栏、秘书 dock。(用户明确否掉「工作桌首页 / 导航收编 9→4」整套——**不做**。)

## 交办五态(一块面,随进度换脸)

说 → 批(授权卡)→ 干(人话进度 + 停下)→ 交货(结果 + 证据 + 下一步)/ 卡住(人话原因 + 下一步,**永不冻**)。

**授权卡定稿字段**:我来做(一句话)/ 会改的文件 / 改完怎么验 /(复杂活)工序图 / 用哪个对话干(◉开个新的·默认 ○接现有)/ 🔓 需要你允许:改这个测试项目 / 「碰到越界或拿不准的,会停下来问你,不硬来」一句总的(不列清单)/ 「想改就直接说」输入框 / 三按钮 **[允许并开始] [按我说的改] [先不做]**。

**[允许并开始] = 方案授权人闸那一下(永不省)**:确认方案 = 授权一段自动执行范围(§0.3 canon),之后不再逐步问;边界复核/准备/绑会话/起链收进这一个动作后头(安全步照跑,只是不再逐个点;Phase A 用户本就演全局主管,这一下同时是边界批准——专职复核 agent 归 Phase B)。

## 条件式工序图

- **简单活:无图、不等待**(卡秒出,两下完事)。
- **复杂活**(AI 判定或用户明说「按工作流来」):
  - 批前:卡上浮出工序图(几个任务、谁等谁;**文字先出、图好了再浮现**,不干等);
  - 批后:图落成**真节点**进「工作流」tab(一任务一节点 + 依赖边),跑到哪亮到哪;
  - **所批即所跑**:批的那张图存档、原样执行、不重拆(防批图 A 跑图 B);
  - 任务节点是窗口**不放运行按钮**(不给绕过审批的口子)。
- 图挂在**项目当前选中的工作流**(2026-07-06 用户拍板转正式默认——真机连用数日与「接着跑/重拆」语义一致;原设想「每单交办自动生成一条工作流·不混手建」降为 Phase D 多工作流成熟时议题,防污染初衷届时一并评估)。

## 交办 vs 智能体(诚实措辞·防吹大)

- 交办 = **有结构、有闸的自动跑一串**(「我说清了,你去搞定」);智能体 = 手动直连一个会话(「我要自己一步步来」),位置功能不动。
- 桥:每单活可一键「看原始对话」钻进智能体页;卡上「用哪个对话干」即桥的起点。
- **禁止**把交办措辞成「agent 层 / 公司雏形 / 多智能体编排」——后端实为顺序连跑(CURRENT 自注 P1≠编排),照实说。

## 地基六件(埋后端,不露脸)

1. **写范围走档位**:授权 scope 由固定档位(=测试项目根 + 固定工具面 + codex-dev 执行角色)装配;**咨询不写权**,只报「会改的文件(target_files)/ 怎么验(checks)」喂授权卡。「写范围为空」卡死从根上消失。
2. **一键合流**:[允许并开始] 一个后端动作 = 确认方案 + 边界复核记录 + 建授权 + prepare + 绑会话 + 起链(全复用现成步骤,人闸=用户那一下点击)。
3. **自动绑会话**:「开个新的」自动建;happy path 永不见「绑会话/needs_binding」。
4. **批前预拆**(复杂活):只读让主管预拆图给用户看(动脑不动手;人闸仍锁执行)。
5. **图存档 + 照图跑 + 起链前复查授权仍 active**(顺手补的真窟窿:批与跑之间授权可能已撤)。
6. **flaky 自动重试一次** + 显示「重试中」(tier-1 codex 偶发早退是既定事实,不装稳);界面老实标注:**自动干目前只在测试项目开通**。

## 不做(本决策明确圈外)

工作桌首页 / 导航收编(用户已否);画布上编辑工序图再跑(推后·涉编址/闸解耦大改);秘书 / 全局主管 agent(Phase B);非测试真实项目(Phase E·高危#1/#4 锁);把顺序连跑包装成编排。
