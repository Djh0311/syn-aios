# 决策：Codex 会话管理与工作流编排纠偏

## 结论

当前产品主线纠偏为两件事：

1. 正确读取和管理 Codex 内容，包括会话完整正文、工具调用、工具结果、项目归属和时间线。
2. 让用户能在工作台中编排 Codex 会话工作流，并在用户审核阶段方案后，让总指导自动分发、等待、回收和继续推进。

工作台不是任务包管理器。任务包继续保留，但只作为内部协议、可导出交接物和审计产物，不作为主界面中心。

## 已知

- 用户明确要求先把 Codex 的内容正确读出来，再做可编排工作流。
- 用户明确要求包括对话正文，Codex 对话的每一个内容都要能读取。
- 用户明确要求能在工作台直接和 Codex 的每一个会话对话，也可以创建对话。
- 用户明确要求编排好工作流后，在完成目标前能自动跑：总指导写好任务，对应开发线读取并开发，完成后反馈给总指导，总指导回收后进入下一步。
- 用户指出当前方向偏到了任务包管理器。
- 用户提供 `BigPizzaV3/CodexPlusPlus` 作为 Codex 会话管理参考源。

## 未知

- Codex CLI / 桌面应用当前版本是否有稳定的外部会话创建、恢复、发送消息和读取回复接口。
- Codex 本地 rollout / sqlite / session_index 在后续版本是否会变。
- 通过 CDP 注入或操控 Codex 官方界面是否足够稳定。
- 工作台内“直接和会话对话”的第一版应走 Codex CLI、SDK、CDP，还是先走一个受控探针。

这些未知不能靠猜。后续必须先做能力探针。

## Codex++ 的参考价值

Codex++ 可以作为参考源，但不能照抄成路线。

可参考：

- 它把自己定位为 Codex App 的外部增强启动器和管理工具。
- 它不修改 Codex App 原始安装文件，而是通过外部 launcher 启动 Codex，并用 Chromium DevTools Protocol 注入增强脚本。
- 它提供会话删除、Markdown 导出、项目移动、Timeline、Provider 同步、用户脚本等增强能力。
- 它的结构包含 Tauri + React 管理工具、Rust 后端、静默 launcher、注入脚本和 `codex-plus-data` 数据层。
- 它明确处理 Codex 本地数据库和本地会话 metadata。

不直接吸收：

- 不直接做会话删除。
- 不直接写 `~/.codex/config.toml` 或供应商配置。
- 不直接注入用户脚本。
- 不直接用 CDP 作为唯一控制路线。
- 不把中转站和模型供应商切换作为当前阶段功能。

## 阶段 3 新顺序

阶段 3 的下一步顺序改成：

1. Codex 会话全文读取：读取选中会话的完整正文、工具调用、工具结果和时间线；默认不塞进全局索引。
2. Codex 会话控制能力探针：确认能否创建会话、恢复会话、发送消息、等待回复、读取结果；只用稳定或可控入口。
3. Codex 工作流编排运行：总指导节点、执行会话节点、任务分发、等待、回收、继续推进。
4. 任务包协议内化：任务包只作为内部消息格式和可导出交接文件，不作为用户主工作流。

## 安全边界

- 不写 Codex 状态库。
- 不改 Codex 原始安装目录。
- 不默认读取或展示全部会话正文。
- 不展示密钥、授权文件、`.env`、token 或 API key。
- 全文读取只针对用户选择的会话或经过明确任务授权的会话。
- 自动编排必须有用户审核阶段方案的入口。

## 对既有成果的处理

保留：

- Tauri 2 + Rust + React + TypeScript + Vite 技术栈。
- 只读索引内核。
- 项目、会话、skills、harness 的元数据扫描。
- 工作流事实层 v0。
- 默认项目 workflow / node / edge 草稿能力。

降级为内部能力：

- 任务包草稿登记。
- 任务包 Markdown 预览。
- 任务包字段编辑。
- 真实任务包文件生成。
- 派发准备检查。

这些能力后续可以服务总指导分发和审计，但不能继续主导产品 UI。

## 风险

- 如果继续沿着任务包文件管理做，会离用户要的“在工作台里和 Codex 会话协作”越来越远。
- 如果直接做自动执行，而没有先确认 Codex 会话控制入口，会做成假工作流。
- 如果全文读取没有隐私边界，会把本地敏感内容暴露到界面。
- 如果照搬 Codex++ 的 CDP 注入，Codex 页面一变就可能失效。

## 当前权威影响

本决策 supersede 以下旧口径中的对应部分：

- “第一版不嵌入 Codex 聊天窗口”：改为“当前要做工作台内 Codex 会话对话能力，但入口必须先探针确认”。
- “不读取或展示会话正文”：改为“需要读取选中会话完整正文，但默认保护，不展示密钥和授权内容”。
- “下一步做 ready 任务包”：暂停，下一步改为会话全文读取和会话控制探针。
