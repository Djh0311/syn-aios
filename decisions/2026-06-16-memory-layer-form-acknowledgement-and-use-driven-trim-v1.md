# 记忆层执行形态认定 + 真用驱动裁剪 决策 v1

日期：2026-06-16
出自：咨询线（Claude）。状态：**用户 2026-06-16 拍板**。

**拍板摘要**：本决策确认——记忆层**作为终局设计成立，但对当前单用户、0 真实记忆阶段偏重、被架空**；**不现在返工**，而是把路线**掉头到真实使用**：L5 必须真写进一条真实记忆，随后进一段**有界观察期**，期末做一次**主动的"过度审计"**，趁数据还少时据实裁剪。多 agent 专属部分挂起不动，4 条不可逆维度保留。代价：纯文档，不返工、不建库、不碰真实执行。不批的后果：那条"承认过度却不改动作"的不诚实结论继续钉在 canon，过度形态持续收税，而且越晚砍越贵。

**一句话判据**：任何记忆表/门要进**当前产品路径**，得答出"此刻服务哪条真实记忆 / 召回 / 冲突"；答不出 = 终局目标、非现在要做。过度审计**趁数据少时主动做**——别等量、别指望被动使用暴露（过度设计不自首）。

## 0. 由来

Claude 的研究/评估曾结论"保持原设计"；用户存疑（结论是否自肥）→ 跨模型红队（GPT[记忆层原设计者，被要求攻自己] + Claude[独立]），咨询线对红队数字去水（记忆层 **17 表**非 54、项目约 **3 周**非 6 月、"40% 治理工时"无依据）→ GPT 实质赢：当前全形态对单人阶段过度，原结论自评。用户提出"留代码、改排期、真用观察"思路，经 Claude 红队细化为本决策。

## 1. 认定

- 记忆层 = 17 表 / 七层 / 多门；**作为终局（多 agent 控制平面）设计，成立**。
- 但**真实正式记忆 0 条、全 fixture，产品切 DB deferred** → 对当前单人阶段**偏重、被架空**（治理跑在数据前面）。
- 原"保持当前全形态"结论**自评 + 承认过度却不改动作**，已被跨模型红队推翻。

## 2. 决定

1. **已建代码不返工**——不现在拆；设计留作终局形态。
2. **路线掉头到真用**：L5 完工线改为**"真写进一条真实记忆"**（非"接线 + fixture 过即可"）；随后进**有界观察期**（拿工作台干真事、看哪些表/门被真填真用）。
3. **期末主动过度审计**：点名"一直空着 / 没挣到存在感"的表/门，**趁数据少（砍最便宜）据实裁**；不被动等暴露、不等大量数据（最贵砍点）。
4. **多 agent 专属**（七角色门、跨项目成熟模式）：**不验、不砍、挂起**，待真有多 agent。
5. **保留**：4 条不可逆维度（子 agent 不写正式 / append-only + status history / `model_export` 外发维度 / 权威-缓存分缝）+ 用户确认门（不自动晋升）。
6. **冻结再加料**：观察 + 审计出结论前，不加表、不切 DB、不上前瞻路径。
7. **真 Codex 执行（K3-B1 / K3-B2）**：独立的安全封禁轨，**不在本路径上**；它被封**不挡**本路径——记忆真写来自真实工作台操作，不需要它。

## 3. 区分（别混）

- **规模 / 质量类**问题（召回准不准、冲突如何处理）——**需要数据量**，可后置。
- **过度 / 冗余结构**问题——**不需要量，趁早主动审**。两类不可打包成"都等数据"。

## 4. 不可声称

不得据此声称：记忆层已验证 / 已精简 / 设计已改 / 真 Codex 已解锁。裁剪动作尚未发生；本决策只定方向与时机。
