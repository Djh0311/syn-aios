# 决策：无限画布底座冻结为 React Flow 深化 v1

日期：2026-06-10
拍板：用户（"可以冻结"）

## 影响面

- 不影响治理期 R0-R5 任何任务（本决策只定方向，不开工）。

## 结论

工作流画布重做为无限画布时，**底座继续用 React Flow（xyflow），往深里做；不换 tldraw 类白板库**。原地装修，不推倒重盖。

## 大白话

两个库都是无限画布——自由平移、随便缩放、没有边界，这点没有区别，所以"无限画布"不是选型分界线。

真正的区别：**React Flow 是接线图工具箱，tldraw 是电子白板。**

- React Flow 天生认识"节点"和"线"：节点有接口、线从接口连到接口、拖节点线自动跟走，小地图、对齐、框选都是现成零件。
- tldraw 是什么都能放的白板，手感 Figma 级，但**不懂"连接"**——画一根箭头连两个框，对它只是三笔画，不是"A 的输出接 B 的输入"。要让它懂工作流，节点接口、连线语义、运行状态全得从零造。

用户要的"AIGC 那种画布"（ComfyUI 类）本质上就是接线图——正是 React Flow 的主场。ComfyUI、n8n 的底层都是同类。**当前画布粗糙不是底座选错，是毛坯没装修**——默认样式、默认节点、没调手感。Xuanji 那个观感不错的执行流程图，底下也是 React Flow，这本身就是证明。

附加因素：tldraw 免费版强制带 "Made with tldraw" 水印，去水印要买商业授权；React Flow 是 MIT，无条件。

## 范围
