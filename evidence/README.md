# 实施与验收记录库

状态：**证据记录，不是产品正本、当前状态、候选方案、任务入口或执行授权。**

本目录保存历史实施报告、测试输出、截图、回执、清单和原始材料。每份记录只能证明它明确写出的：

- 受检版本或提交；
- 输入、环境与场景；
- 验证方法和证据等级；
- 当时得到的结果；
- 明确没有覆盖的边界。

文件名中的“权威”“最终”“冻结”“完成”“真实”不表示它今天仍是产品权威，也不允许把离线、夹具、隔离环境、浏览器、桌面应用、真实服务提供方或发布等不同证据等级互相替代。

## 使用规则

1. 判断当前能力时，先看 `docs/current-state.md`，再核对当前版本库（Git）、源码和直接验证。
2. 判断产品应该是什么时，回到当前产品正本和仍有效的正式决定；不得从证据报告反推新产品要求。
3. 若证据与当前源码冲突，保留它作为历史记录，并以当前源码和新鲜验证说明差异。
4. 若证据中夹带用户拍板或长期产品要求，先把内容和来源提取到正式产品文档，再继续把原文件按证据处理。
5. `raw/`（原始材料目录）、备份和大体积材料可能含真实运行数据或敏感上下文；不要把它们复制进产品知识正文、提示词或普通索引，也不要在整理时批量展开。

Syn 的知识基础设施可以受控索引和引用这些记录，帮助智能体追溯历史，但索引命中不会把历史证据升级为当前事实或产品正本。敏感性、可见范围和来源边界仍然有效。

本轮不批量移动既有证据。后续迁移必须保留路径映射，校验文件数量、内容哈希和引用完整性。
