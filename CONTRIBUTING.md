# Contributing to Syn

Syn is pre-1.0 and under active development. The public tree is a maintainer preview, not a finished product with a stable contributor process.

## Before you start

- Read the root [`README.md`](README.md) and [`docs/current-state.md`](docs/current-state.md).
- Treat product canon, current implementation, acceptance evidence, and harness workflow as separate things.
- Do not send secrets, personal data, API keys, or local absolute paths.

## How to help

Issues and pull requests are welcome after you can reproduce a problem from a public commit. Please say:

1. what you expected;
2. what you observed;
3. the commit or tree you used;
4. whether the evidence is a clean clone, a local working copy, or an isolated fixture.

Do not treat isolated tests, handoffs, or old screenshots as proof that a feature is released.

## Development notes

If you are working inside this repository with the current maintainer workflow, start from `AGENTS.md`. That workflow is for maintainers. It is not a product feature and does not replace GitHub review.
