# AI Agent Workbench Product Line

Syn 是面向当前用户的个人 AI 工作台产品线，覆盖会话、知识、记忆、任务、工作流、Agent、连接器、工具、审计和日报等协作能力。

## 开发入口

先读 `AGENTS.md`，再按 Harness Lite 的唯一链进入：

```text
docs/harness/plan.md → 当前 stage → 唯一 current leaf
```

当前授权只看 `docs/harness/authorization.json`。README、产品计划、合同、任务包、handoff 和历史状态都不授予开发权限。

产品方向与架构事实保存在 `decisions/`、`docs/plans/`、`docs/contracts/` 和源码中；采用前必须结合当前 Git 和直接验证重核。旧治理状态文件已移入历史目录。
