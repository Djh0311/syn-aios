# Syn 全界面重构 · 设计简报 v1(impeccable shape 产物·待用户确认)

日期:2026-07-14 深夜 · 流程:impeccable `shape`(发现访谈已做,本简报经用户确认后才进线框/实现) · 上游拍板全部有效:宪法(五态/打断三级/回顾面)、零换皮、交货面骨架、两禁令(无完成横幅/技术细节进下钻)。

## 1 · 这是什么

Syn 治理工作台全部界面(体检 77 面归为五类页面)按统一规范重构。单人中文用户,macOS 桌面,每天长时间使用;工具应消失于任务(product register)。

## 2 · 每类页面的唯一问题(=宪法)

| 页面类 | 覆盖 | 唯一问题 |
|---|---|---|
| A·五态工单面 | 交办页(说/批/干/交货/卡住) | 各态照宪法五态表 |
| B·回顾列表面 | 记忆中心/技能/知识库/历史/会话 | 我要找的那条多快找到 |
| C·中心看板面 | 首页/harness 板 | **系统总览**(用户拍):现在整体什么状态、哪里等我 |
| D·右栏与抽屉 | 通知/待办/运行中/秘书 | 一眼可见但不打断 |
| E·弹层与确认 | 授权/确认/权限 | 它要动什么·我敢不敢 |

## 3 · 视觉方向(已拍,不再问)

Restrained·零换皮:现有暖纸底/青绿/宋黑分工全部沿用。场景句:一个人白天与深夜长时间盯着的本地治理台,暖纸低刺激,状态色是唯一的情绪。锚:现 App 风格+Linear 的壳内滚动结构。

## 4 · 布局策略(本简报核心新约束·用户访谈拍)

1. **壳固定,容器内滚**:页面不出现整页滚动——外壳(顶栏/侧栏/页面骨架)恒定 100vh,滚动只发生在面板/列表容器内部。所有五类页面都按此重排;
2. **紧凑一档**:卡片/列表行内边距收一档,一屏多见内容少滚动;
3. **回顾面结构三案待对比**(用户「都给我看看」):右侧固定详情栏 / 原地展开 / 滑出抽屉——线框阶段用真实数据渲染三案,选定后四个回顾页统一;
4. 首页=系统总览:统计行+各区块概览(等我的事作为总览中的一个区块,不是主角)。

## 5 · 关键状态
