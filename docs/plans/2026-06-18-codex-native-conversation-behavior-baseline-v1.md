# Codex 原生对话行为 · 参考基线 v1（P0 产出 ②）

日期：2026-06-18
出处：咨询线（Claude，咨询秘书）实地观察真实 Codex 桌面 app（`com.openai.codex`，用户已装）。
用途：[对话模块原生体验阶段计划](2026-06-18-conversation-module-native-experience-phased-plan-v1.md) 的"照搬 codex"规格底本——后续每个设计点对照本文，**不自创**。
范围声明：本文只记 **UX/行为模式**，不含用户私人会话内容。

## 一句话判据

做对话模块任一设计点时——**先翻本文看 codex 怎么做；本文没记的，再去 app 现看；都不自创。**

---

## 1. 整体布局

深色主题，三栏式：**左侧栏（导航 + 会话列表）｜ 主对话区 ｜ 底部撰写区**。

## 2. 左侧栏

- **顶部操作**：新对话（`⌘N`）· 搜索 · 插件 · 自动化。
- **会话列表 = 按「项目文件夹」分组**：crazytown / 金融 / harness-engine / gamework / game-harness / agents / kt-erp / videocut … 每组下挂该项目的对话，带相对时间（"1 天 / 3 天 / 4 天"）；空项目显示"暂无对话"；顶部另有几条最近/未分组对话 +"展开显示"。
- 选中对话高亮；**运行中的对话带 spinner**。
- **底部**：对话（分区）· 设置。

## 3. 新建对话（`⌘N`）—— P2 照搬重点

- **情境化大标题**：按当前项目生成，如"我们应该在 kt-erp 中构建什么？"。
- **居中撰写框**：占位"随心输入"。
- **新会话绑定 = 撰写区下方三个内联选择器**（关键）：
  - **项目**（`kt-erp ▾`）· **执行模式**（`本地模式 ▾`）· **git 分支**（`main ▾`）。
  - → "新会话在哪跑"在**新建撰写区内联选**，默认=当前项目，**不弹独立 folder-picker**。
- **建议列表**：codex 主动提的可做项（按项目）+"将你常用的应用连接到 Codex"。
- 发送 = **↑**（圆形上箭头）。

## 4. 消息渲染 —— P3 照搬重点（与工作台现状差最大）

- **助手消息 = 平铺 markdown 文本**：左对齐、**无聊天气泡**、正文清晰、带 inline `code` 药丸。
- **工具/动作 = 灰色紧凑状态行**：小图标 + 文案，按文档顺序与正文**交错**。样式如：
  - "✎ 正在编辑 1 个文件"、"▣ 已读取 4 个文件"、"▣ 已创建 1 个文件"
  - "▣ 已运行 `printf … && git status --short -- …`"（显示实际命令，过长截断）
- **思考**：底部"正在思考"指示。
- **进行中的子动作**：实时状态行，如"正在搜索 task-queue.md 文件夹中的文件"。
- **上下文压缩**：横向分隔线"—— 上下文已自动压缩 ——"。

## 5. 运行态 —— 富信息

- 侧栏该对话 **spinner**。
- **步数进度药丸**（底部居中）："第 5 / 5 步 · 10 个文件已更改 `+312 -30`"。
- **常驻"进行中的目标"条**：目标文本（截断）+ **计时**（14h 57m）+ 编辑 ✎ / 暂停 ⏸ / 删除 🗑 / 展开 ›。
- 撰写区右侧：**STOP（■）**；空闲时为**发送（↑）**。

## 6. 撰写区（活动对话）

- 占位"要求后续变更"。
- 工具条：**+（附件）· 替我审批（审批模式 ▾）· 目标 · 模型（`5.5 超高 ▾`）· 发送(↑)/停止(■)**。

---

## 7. 照搬要点 × 与工作台现状的差距（诚实）

| 维度 | Codex 原生 | 工作台现状 | 照搬动作 / 所属阶段 |
|---|---|---|---|
| 渲染范式 | 平铺文本 + 灰色工具行 | 聊天气泡 + 开发者字段墙 | **改成 codex 范式** → P3 |
| 会话模型 | 项目文件夹分组 + 新会话内联(项目/模式/分支) | 会话已按项目分组；发送卡 cwd、只一条能发 | 放宽绑定(P1) + 新建内联选择器(P2) |
| 回复 | 真回显（流式 + 工具行 + 思考） | 发完不回显、卡死 | 回复整段回显 + 解锁(P1)；静态富信息渲染(P3) |
| 运行态 | 步数/diff/目标/计时/停止 | 只一个 running + 锁死 | 完成态(P1)；实时步数/计时/思考流 = **P4 流式** |

## 8. 对计划的影响（诚实泼冷水）

- **"照搬 codex"是大工程**：codex 对话 UX 很厚（工具行渲染、运行态药丸、目标条、项目/模式/分支模型、建议、审批模式）。工作台现状离它很远，这不是贴层皮能糊弄的。
- **本轮（P1–P3，回复整段）能照搬到位的**：任意会话可发 + 回复回显（P1）/ 新建对话内联选择器（P2）/ 渲染范式（平铺文本+工具行）+ 静态富信息 + 会话模型（P3）。
- **本轮不做（按用户拍板）**：实时运行态（步数进度 / 计时 / 思考流）属 **P4 真流式**——这些信息要 codex 流式输出真接出来。
- 可渲染性提示：工具行 / 思考 / 步数等富信息**源自 codex 自己的会话流**；工作台读 rollout → **静态历史里这些事件可渲染（P3 能做）**，但**实时态需流式（P4）**。
