# 计划：Codex 中转（甲）· 通向工作流编排的第一级跳板 v1

日期：2026-06-17

出自：咨询线（Claude）。性质：计划文档。用户 2026-06-17 在**核对蓝图正本**、确认与蓝图的张力后，拍板"**甲·中转当有意识的跳板**"。

## 拍板摘要

- **要做的事**：让 Syn 真能把你打的一句话**转发**给 Codex 跑（中转 / relay）——安全级 = 你直接用 Codex + 三条本分。作为通向蓝图"角色编排"终局的**第一级跳板**。
- **代价**：一轮"把发送接到真起 Codex"的实现（建在已做好的会话引擎上）；第一次真让 Syn 驱动 Codex（轻、但真，要你点一次头）。
- **不做的后果**：Syn 永远"看得见、动不了"；你真用的卡点（"它不能真干活"）一直在。
- **与蓝图的关系（重要）**：这是**对蓝图第一版闭环（角色中介）的有意偏离**——用 relay 换早期可用。**它是跳板、不是终点**；终点仍是蓝图的"项目主管派任务包 → 子智能体 → 审查 → 主管总结"编排（§11 / §12 / §26）。

## 三条护栏（让跳板不变歪路）

1. **它是第一级、不是终点**：终点是蓝图的角色编排；中转只先把"真执行"这条腿打通。
2. **别硬成聊天客户端**：设计时**留好以后在"用户 ↔ Codex"中间插入角色 / 任务包 / 记忆注入 / 审计的接口**，不要写成只能直连。（否则就违背蓝图 §1"不是聊天软件"。）
3. **记账这是有意偏离**：本计划即此记录；若中转长期化，需回看是否该升级为角色中介。

## 目标 / 范围 / 不做

- **目标**：你在 Syn 里打一句 → 转给你指定的 Codex 会话 / 项目 → 它真跑、真写那个项目 → 输出回到对话。**手动、一对一、你点一次发一次。**
- **范围**：建在已做好的会话引擎（发送框 + 输出回流）上；接通"发送 → 真起 Codex"。
- **不做**：自动连环驱动（乙）、多 agent 并行、绕过你的确认、把发送做成自动触发；**不撤安全机制**（走轻法、不拆门）。

## 安全（relay = 你直接用 Codex 的级别 + 三条本分）

1. **原话转发**：发出去啥你看得见（若 Syn 加了上下文 / 记忆注入，也明示真正发了啥）。
2. **转到你指的项目 / 会话**：别发错地方、写错项目。
3. **你点一次、发一次**：不自动连环。
- `.codex` 是 Codex 自己正常写（它本来就写）、Syn 不额外碰；外发只有 Codex 调模型那一下、Syn 不加料；能看回执 / 能停 / 能回滚。

## 步骤

1. **设计「老实中转」草案**（咨询线）：三条本分 + 安全级 + 看回执 / 停 / 回滚 + **怎么在现有执行机制里按"中转轻法"接通**（不走乙的重审批）+ **留好以后插角色的接口**（护栏 2）。
2. **你拍板**（轻、一句）：看草案点头，落一句决策（头一回让 Syn 真驱动 Codex，虽轻但真）。
3. **交 Codex 实现**（在你 Mac）：发送 → 真起 Codex 跑你这句、在你选的项目、输出流回对话；三条本分焊死 → 独立复核 → 咨询线审实物。
4. **你真机验**：发一条真消息，Codex 真跑、真写你那个项目、输出回来。过了——**中转活了。**

## 阶梯（定位）

**甲·中转（本计划）→ 中间·半自动（主管派活 + 你批步）→ 乙·工作流连环编排（蓝图终局，§11 / §12 / §26）。** 中间 / 乙 现在不碰，留终局；那道重门 + 真库切换 + 记忆真攒，是乙的前置。

## 不接受为

- 不接受为终点（它是跳板）；不接受为 Syn = 聊天客户端；不接受为自动连环 / 解锁乙；不接受为撤掉安全机制；不接受为真机超大压测已做。
