## A·设计方向(方向拍死·细节未拍)

**A 不是**「把 `--json` error 流灌进一个面板」。**A 是**「捕获原始错误 → 翻译成人话 → 按 run 上脸」——把 fix8 已经在做的「供给类失败人话」哲学,从个别类目**推广到通用诊断层**。

- **两层脸(沿用口供上脸+黄牌范式)**:默认脸 = 人话摘要(这次为什么挂、能怎么办);下钻 = 原始错误原文(给要深挖时看,默认收起)。人话优先,和秘书/run-history 同哲学。
- **翻译层是核心工作**:原始 error → 人话,需要一张「已知错误族 → 人话」映射(codex 记忆子系统报错、断供、超时、沙箱拒绝、命令 exit≠0…),unknown 保守兜底成「未识别错误·附原文」(不硬编人话骗人——延续保守归一化纪律)。
- **接点**:与 C5(闭环上脸+审计)相邻——error 事件本就是 audit 事件的一类;但「人话翻译层 + 专门错误视图」是新地。落位(B2 尾追一片 / Phase C)C1 清后再定。
