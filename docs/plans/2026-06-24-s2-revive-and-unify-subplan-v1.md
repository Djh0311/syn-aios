## 分子阶段（每个 → 一份任务包，逐个派发、主导线核实物）

### S2-1 · 接缝勘测（主导线·只读·先做）
- **做什么**：读 `ProjectWorkflowCanvasView.tsx:1309`（A-B 集成缝）+ A 面板（Governance/Execution/Memory）+ A 命令/读模型，摸清现状：哪些 A 命令/读模型**已接到 live 前端**、哪些 orphaned；现在角色循环 UX 走到哪（有无可用流）；逐个 A 面板分类（已可用保留 / 需重新装配 / 纯协议裸面板待清）。
- **产出**：一张**接缝 wiring map** + 据此把 S2-2..S2-5 的任务包细化（现在的子阶段描述是骨架，勘测后才钉死每个包改哪些文件、接哪些命令）。
- **定位**：**主导线亲做**（读码分析、informs 后续任务包），不派发；轻档·零风险。

### S2-2 · 方案 + 授权 surface（对话 → 方案 → 你批）
- **做什么**：把 **项目咨询出方案**（`create_project_consultation_proposal` / 渲染 markdown）+ **方案授权制**（`create_plan_authorization` / `record_plan_authorization_user_confirmation` / `record_global_boundary_review`）接到现有前端，让「和 AI 聊 → 出结构化方案 → 你审 → 批 = 授权一段范围」走通。
- **带可用性 C①**：方案授权 UI **用人话讲清这次会干啥**（目标/范围/必停点），取代你记不住的黑箱锁。
- **定位**：**轻档**（不真跑 codex，只到方案+授权；后端命令/读模型现成、复用）。

### S2-3 · 派发 + 汇报 + 复核 surface（项目主管 → worker → 看结果）
- **做什么**：把 **项目主管拆任务**（`preview_project_director_task_plan` / `prepare_authorized_auto_dispatch`）+ **worker 真派发**（走 S1 已合一的强闸路径）+ **worker 结构化汇报**（`record_worker_structured_report`）+ **事实确认**（`record_project_director_process_fact_decision`）+ **全局复核 + 看结果**（`record_global_final_result_review` / `record_user_result_decision`）接到现有前端，让「批了的方案 → 主管派 worker 真跑 → 汇报 → 确认 → 看结果」走通。
- **定位**：**碰高危#1**（角色循环真跑 codex·测试项目轻档·S1 闸已验 path-lock）；若主管驱动多 worker 连跑碰**高危#4**（4 护栏在、圈测试项目、不放开非测试）。任务包须钉死：默认仅测试项目、走 S1 强闸、4 护栏、真跑验证单列。

### S2-4 · 记忆闭环全救 surface
- **做什么**：把**完整记忆闭环**（观察 `observation_store` → 候选 `memory_candidate_store` → 正式 `formal_memory_store` → lint/冲突 `memory_lint` → 实体关系 `memory_entity_relation` → 成熟模式 `mature_pattern` → 任务包召回 `task_memory_packet`）接到现有记忆中心 UI，让 **worker 确认的事实 → 下个 worker 召回**走通、记忆中心可用、可看可改。
- **定位**：**轻档**（后端记忆层活·104 测试含 memory_lint 等全绿，救活=接前端+读模型，非重写）。**全救不做最小版**（用户硬边界）。

### S2-5 · A 旧面板整理 + 可用性收口
- **做什么**：按 S2-1 map，**整理** A 旧面板——保留已接后端可用的、清掉「纯协议裸面板」（如 `AgentExecutionPanels` 那种把 prepare/confirm/store_revision 摊给用户的）；**收字段**（显示边界 §6：候选/权限/readback/审计进详情/侧栏，画布主区不糊）；**编辑 UX**（停止直改 / 运行中进编辑视图 / 大部分操作不切视图 / 砍多余双状态提交）。
- **定位**：**轻档**（UI 整理，整理非重建）。
