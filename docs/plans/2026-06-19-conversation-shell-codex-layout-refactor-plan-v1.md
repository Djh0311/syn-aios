## 重构布局照 codex（视觉保持水墨，仅此视图内）

- **左 = 会话列表**：顶部 `新对话 / 搜索`；下面会话**按项目文件夹分组**，每条一行（标题 + 时间 + 运行 spinner）。
- **中 = 一整条对话**：标题 + 平铺 transcript（助手平铺文本 + 灰色工具状态行 + 思考/压缩分隔）。
- **底 = 撰写区**（复用现有，已验过的发送回路）。
- **删掉**：软件层卡片、项目/对话下拉条、"软件层/会话层"分区头。
- **视觉 = 水墨皮**：配色/字体/质感全用现有 ink token（`styles.css` 那套），**不抄 codex 深色外观**——codex 只管"什么放哪"，不管"长什么色"。

> 这个视图自己的"信息/入口"= 新对话 / 搜索 / 会话列表，归进上面 codex 式左栏。**不涉及 App 的其它导航入口。**
