# 交互正本 v1(提案·待用户拍板)——Syn 工作台交互宪法

日期:2026-07-13 · 状态:**草稿·未拍板**。拍板后进 `decisions/`,此后一切 UI 任务包的验收对照本文;修订权=用户,修订驱动=使用实录(§6),禁止凭想象改布局。

> 本文不发明任何新交互原语。它只做一件事:把已拍过板的隐性模型(五态旅程、两轴决策、「项目=最高业务对象」、黄牌哲学、人闸清单)升格为**显性宪法**,终结「每个任务包自己重新谈判布局」的历史(工序图退役/相位机退役/上下改左右……的病根)。

## 一、五态与唯一问题(核心表·一切 UI 判断的准绳)

**UI 好不好的唯一标准:用户在每一态的「唯一问题」多快被回答。**

| 态 | 用户唯一问题 | 主注意力必须给 | 答案的证据形态 | 典型违宪 |
|---|---|---|---|---|
| **说**(提案) | 它理解对了吗 | 方案原文+它自列的验收标准 | 方案卡(所批即所跑) | 让用户读机器内部结构才能确认理解 |
| **批**(授权) | 它要动什么·我敢不敢 | 写根/工具/范围与边界意见 | 授权卡=范围三要素+advisory 意见(意见不是闸) | 批准按钮旁堆教学文案(07-11 已拍删) |
| **干**(执行) | 需要我吗·还要多久 | 唯一的活动指示+进度 | 逐格亮;不需要我=零打断 | 把原始日志当进度泼给用户 |
| **交货**(验收) | 能信吗·证据呢 | 口供+可当场点开的证据 | 口供上脸+黄牌+[属实,沉淀] | 结论与证据分离在两个屏 |
| **卡住**(决策) | 为什么停·我选哪个 | 人话停因+死配对选项 | 停因一句话+互斥按钮·永不冻 | 泛化错误码;可点但无效的按钮 |

## 二、对象×态(骨架矩阵)

对象层级(蓝图已拍):**项目 > 工作流 > 工单(方案/授权/派发/口供/终标)> 记忆候选**。

- **项目**:永远是最高导航层与入口;任何态都不许把 agent/chat/timeline 提为最高对象(蓝图「明确不吸收」)。
- **方案**:说态的主角 → 批态变形为授权卡 → 之后只读留痕。同一对象**变形不搬家**。
- **工单**:干态的主角(格子/画布节点)→ 交货态变形为口供载体 → 卡住态变形为决策卡。
- **记忆候选**:只在交货态出现([属实,沉淀]);其余四态不可见=零打扰。
- **审计/账本**:任何态都不是主角;常驻"可查"位(§三记账级)。

## 三、打断宪法(注意力=系统里最稀缺的资源)

三级,判据=两轴决策的「人必须在场」:

1. **打断级**(弹到面前,仅两类):卡住态的用户决策;高危授权请求。
2. **常显级**(不打断但一眼可见):干态进度、待批队列计数。
3. **记账级**(默认沉默,可查):advisory 意见、警告、audit、黄牌——黄牌哲学=呈现不阻断,归此级。

**违宪判据(可机械检查):** 记账级内容出现在打断位置=违宪;打断级被埋进记账=更重违宪。用户"用起来不舒服"优先往这里查——多数不适=注意力被不配打断的东西打断,或该打断的没跳出来。

## 四、布局恒定原则(止住反复翻修)

1. **一屏一主角**:任何时刻主区只服务当前态的唯一问题;次要信息进常显条/抽屉。
2. **位置恒定**:对象跨态可变形、不许搬家(肌肉记忆>局部最优)。已拍布局固化于此:左交办窄栏+右画布大区、历史栏=悬浮覆盖、[接着跑]在卡住脸不在历史栏。此后改布局=修宪=用户拍板,不再是任务包内自由裁量。
3. **文案三禁**(全部已拍,此处集中成宪):禁教学/标签文案;禁机器内部术语上脸(人话已拍·C6);禁死按钮(可点必有效,不可用则不可见或给人话原因)。

## 五、状态形状即代码形状(给拆巨石定方向,债在正本之后还)

前端状态的一等公民应=「当前态×当前对象」,而非 N 个孤立 useState。`ProjectJiaobanPanel`(46 useState 相位机巨石·评审前端 P1)的拆分方向:**一个五态状态机+五个态组件**;拆分包的验收=对照本文(每个组件服务哪一态、答哪个唯一问题),而非行数达标。styles.css 超线同理——按态归档样式,不按页面。

## 六、修订协议(薄正本+实录驱动)

- **实录格式**(一行一条,攒 `docs/ux-friction-log.md`):`日期 | 态 | 想答的问题 | 实际成本(多点了N下/找了哪里/被什么打断)`。
- 每个 UI 包收口前扫实录;违宪被抓记 `docs/harness-catch-log.md`(与后端同一账本)。
- 正本修订=用户拍板;v1 预期有错——市面无先例意味着第一版必然要被实录纠正,**薄+快改**优于大设计(07-11「整台原型永久暂停·实机迭代胜出」的板继续有效)。

## 七、不做什么(边界)

- 不发明新交互原语;不做第二入口(已拍);不为"看起来专业"加任何仪表盘式装饰——每个像素必须服务某态的唯一问题;
- 本文不排期、不自动生成任何 UI 任务包;拆巨石/样式归档=拍板后按包走。
