## 0. 一句话方向(分层复用,非救活、非二选一、非重建)
产品 = **对话 → AI 出方案 → 你授权 → 自动跑 → 你看结果** 的角色循环(北极星不变)。落地方式 = **分层复用**:

- **把 A 的强闸搬到 B 的真执行边界**,path-lock 作必要条件。

## 1. 事实(审完 + 探针,防遗忘)
- **A 线后端活着**:`cargo test --lib` 580/0,A 线行为测试 104 条绿(方案授权/全局复核/主管/记忆 lint·冲突·实体关系)。真 codex 端到端没测(那是 26 个 ignored)。
- **A 死因 = UX/前端 + 细分的对话&工作流不行**(用户口述):A "大部分功能做出来了,但前端完全不能用、对话和工作流这两块细分功能不行"。
- **B = "中间版本"**:用户**有意**建来强化对话(relay/agent/会话)+ 工作流(画布/链)。**现有前端是它调整过的版本、可用。** 不是误打误撞重复造 A。
- **两套闸/路径并存**:A 强闸 `decide_real_execution_command`(7 判据)/ B 弱闸 path-lock(抄 5 处)。
- **sqlite `workbench_sqlite_*` ~1.6 万行 = R3 封存迁移**(撑工作流状态 + 整套记忆表),用户拍过"先不翻闸",非死码。
