日期:2026-07-08 · 出自:主导线。**用途**:正本设计文档(愿景/架构/中间版/定稿)写的是各自成文时的意图;产品此后长出的大量能力只存在于 `CURRENT.md` 的证据流水里。本文 = **逐面盘点「今天真有什么」**(每条均经主导线核实物/真机验收),供整台原型使用:**原型的「现在就有」徽标只认本文;愿景取正本文档;两者冲突以本文 §二 为准。** 本文是快照(2026-07-08·**深夜刷一版**:并入当日落地——工作历史左栏/秘书看板与右栏归队/超时自动重拆/重拆带已完成事实；**07-19 S1C 补刷**:工作历史移位并正名为历届方案索引),再往后以 CURRENT 为准、每阶段收口顺手刷。

## 一、按面盘点(对应原型六面)

### 面1 · 首页/工作台外壳
- 现状:左导航九入口;右侧栏 = 秘书 brief(待拍板计数/风险/建议)+ 详情面板;「打开秘书」钮。
- **没有**:项目群总览首屏;⌘K/NL 入口(Phase C);多项目并行视图(Phase E)。

### 面2 · 项目页(最厚·全部真机验收过)
**交办 tab(默认页)·五态一块面**:
- **说**:目标输入 + [出方案] + 「出方案会带上 N 条项目记忆」提示(有正式记忆时);
- **批(授权卡)**:我来做 / 会改的文件 / 怎么验 / 用哪个对话干(收起一行·展开最近5条可搜·「开个新的」·行尾**看原始对话**)/ 🔓需要你允许 / 想改直接说 / [允许并开始][按我说的改][先不做];**旧方案黄条**(非今天生成);**纯建议警条**(方案不改任何文件时)+ 主按钮改道[重新出方案(要动手)];**全局主管意见(批前边界)**块——自动、async 不挡批、按方案幂等、looks_ok/caution/mismatch 人话;(复杂活)**工序图**:「按工作流来」开关(AI 建议默认)·步骤框纵向流+箭头·图好高亮 pop+「你批的就是这份图」·**所批即所跑**(照图跑不重拆);
- **干**:逐格亮 + 「主管正在拆任务…(最长十几分钟)」+ [停下] + 看原始对话;新会话单显「正在为这单活新建会话(约 1 分钟)」;
- **交货**:「✓ 做好了(有 N 项要看一眼)」;产出行;**每任务行 = 标题 + 自述(worker 汇报)+ 徽章**(绿✓ / **黄牌⚠**[自述没干完·失败·没交汇报] / 执行态红灰优先);绿行 **[属实,沉淀]** → 记忆候选;**全局主管意见(结果复核)**块——自动、async、按轮幂等、pass/needs_rework/needs_human_check + 建议动作([按建议打回重拆]·意见不是闸);看原始对话/看最近对话;
- **卡住**:人话停因 + 死配对按钮**绝不零按钮**([接着跑,不用重批] / [重新出方案] 等)——**永不冻**;
- **自动行为(不露脸但塑造体验)**:崩溃残料三层自愈;界外角色钳位;tier-1 抽风 retry 一次;额度死/断供人话「codex 服务不可用」;纯建议方案开工口直接拒(不建垃圾授权);**任务超时自动打回主管重拆一次**(交货/卡住脸见「已自动打回主管重拆 1 次」);**重拆自带「本单已完成·别重做」事实块 + 项目记忆**。
**工作流 tab**:画布(React Flow)——只读运行视图 + 可编辑多工作流(新建/编辑/提交写回)+ 全屏 HUD + 发令台 + 交办的**任务级节点+虚线依赖边**落画布、跑到哪亮到哪(任务节点只看不点);「运行选中节点」= 手动挡 override 非主路径。
- **历届方案索引 = 已实现(07-08 数据能力；07-19 S1C 移位正名)**:桌面位于左对话与右方案/交货实体之间，点选只切右侧实体、不扰动对话；目标一句+九态人话状态+日期，缺方案实体的旧单如实标「旧单·无方案记录」；筛选 chips / 旧单只读详情卡仍在，[接着跑]归卡住脸。后端继续复用 `list_project_run_history` 读模型(方案为脊·链时间窗归属如实标 exact/time_window)。

### 面3 · 智能体页(真机验收过)
- 会话列表:按软件分组 / subagent 过滤 / 标题截断 / 拖拽改宽;会话流:虚拟化 + 按轮分组 + 过程折叠;绑会话 Enter 直发(relay·唯一真指挥 codex 的手动通道);`focusedThreadId` 选中态(交办「看原始对话」跳入即此)。
- **没有**:反向标注「这条会话属于哪单交办」(构想·待拍)。

### 面4 · 记忆中心
- 候选列表(含交办[属实]产生的)/ 正式记忆 / 生命周期治理命令(候选→转正等)/ entity-relation·lint·pattern 各面板;采集 = 治理命令钩子自动攒候选 + **确认制**(未经确认不自动沉淀);召回 = 正式记忆 top5 进咨询/预拆/重拆 prompt。
- **挂账**:记忆中心**布局重做**(Phase D·本原型的面4 兼任其设计稿);inbox 复位。

### 面5 · 秘书
- 右栏 brief:**待你拍板**三组(待批方案 / 主管提醒[needs_human_check·human_verify·mismatch·caution 刻意不入] / 记忆候选)+ 计数 + 文字去处 + **[让 AI 解释现状]**(按需·约 1-2 分钟·会话内缓存)+ 边界话「提醒不是命令·秘书零写入」。
- **秘书看板 = 已实现(07-08 当日)**:专门界面·四泳道(等你拍板/主管提醒/记忆候选/风险建议)·卡片只读不许拖·[让 AI 解释现状]在看板;**入口(07-08 对调后)**:右下角浮钮=开看板界面,右侧栏图标=开侧边栏摘要(与通知/待办同一套面板开法·不再单独浮层)。
- **没有**:机会简报(B3+ 已拍收编排后);对话式秘书(Phase C 同期)。

### 面6 · 审计
- 现状:审计事件**落库全**(工作流状态 audit_events + 主管两意见的 store 内嵌审计),开发者详情面板可看原始。
- **没有**:「给人看的审计」界面(按单/按天时间线)——原型面6 的正题。
