# Decisions Bridge

This file exists so the installed harness can find a `docs/decisions.md` entrypoint.

Current decision authority remains:

- `decisions/**`
- current user instruction
- `docs/harness/plan.md` → current stage → current leaf
- `docs/harness/authorization.json`
- `README.md`

Do not duplicate full decisions here. Add, supersede, or correct decisions in `decisions/**`.
