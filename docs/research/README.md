# 研究资料目录

本目录保存外部项目研究、比较、测量设想和冲突分析。研究可以提供证据、反例和设计启发，但不会因为写在这里就成为 Syn 的产品要求、当前计划或实现事实。

采用研究结论时必须经过以下一种出口：

- 已由用户确认并写入 `../product/syn-product-canon-v1.md` 或现行专题正本；
- 仍未确认并登记到 `../product/candidate-register-v1.md`；
- 只作为历史来源保留。

文件效力统一看 `../product/authority-register-v1.md`。不要从研究文件中的“建议、应该、下一步”直接开工。
